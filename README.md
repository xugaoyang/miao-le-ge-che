# 喵了个车 · H5 可玩原型

微信小游戏《喵了个车》的玩法验证原型：**挪车解谜 + 槽位三消**，题材是可爱的猫咪小车。

> 目的：在投入 Cocos Creator 正式开发前，先用最低成本验证“是否上头”。

## 怎么玩

1. 点击停车场里的小猫车，车头方向（耳朵、大灯那一端）前方没有遮挡就能开出去。
2. **按住小车不放**可以预览路线：绿色表示能走，红色会标出挡路的车。
3. 开出的车进入底部 7 个等候槽位，**凑齐 3 辆同色**，猫咪巴士就会开来接走它们。
4. 槽位被占满就失败，所有车清空即过关。

## 运行

纯静态单文件，无需构建：

```bash
python -m http.server 8000
# 浏览器打开 http://localhost:8000 ，用手机模式（F12 → 设备模拟）体验最佳
```

调试：控制台输入 `mlgc.go(5)` 直接跳到第 5 关。

## v0.2 更新内容

| 方向 | 改动 |
|---|---|
| 关卡生成 | 改为“随机密铺 + 求解修复”：开局可直接开走的车，前期约 40–50%，后期降到约 20%（v0.1 全程约 50%）；新增占 2 格的长车；全部关卡保证有解 |
| 难度曲线 | 锯齿形：每 5 关一个 👑 Boss 关（金币翻倍），Boss 后一关放松；去掉 v0.1 第 2 关的断崖 |
| 辨识度 | 颜色从 9 种减到 7 种，每种配一个符号（●★♥▲◆✚☾），色弱也能区分 |
| 车型 | 长方形车身，车头有猫耳和大灯，方向一眼可见 |
| 路线预览 | 长按小车显示路线，被挡时红线 + 挡路车红框 |
| 撞车反馈 | 被挡的车冲到挡路车前弹回，配“哐”声和震动，挡路车冒出“！” |
| 猫咪巴士 | 三消时巴士开进来，3 只猫上车后开走 |
| 连击 | 3 秒内连续三消显示“连击 ×N”，音调逐级升高 |
| 危险预警 | 剩 2 格时槽位红框闪烁、显示“只剩 N 格”、心跳音效 |
| 新手引导 | 第 1 关手指动画指向推荐的车 |
| 道具 | 第 3 关解锁并各送 1 个；改为库存制，看一次广告得 2–3 个，或用金币购买 |
| 复活 | 阶梯复活：第 1 次看广告，第 2 次花 60 金币 |
| 金币用途 | 可买道具、金币复活；新增猫咪图鉴，每送 30 只同种猫回家领 50 金币 |
| 其他 | 棋盘贴近槽位；提示条不再遮挡棋盘；新增声音开关 |

左下角显示本次会话的模拟广告观看次数，方便内测时估算人均广告次数。
