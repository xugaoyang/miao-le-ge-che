# 喵了个车 · H5 可玩原型

微信小游戏《喵了个车》的玩法验证原型：**挪车解谜 + 槽位三消**，题材是可爱的猫咪小车。

> 目的：在投入 Cocos Creator 正式开发前，先用最低成本验证“是否上头”。

## 怎么玩

1. 点击停车场里的小猫车，车头方向（耳朵、大灯那一端）前方没有遮挡就能开出去。
2. **按住小车不放**可以预览路线：绿色表示能走，红色会标出挡路的车。
3. 开出的车进入底部 7 个等候槽位，**凑齐 3 辆同色**，猫咪巴士就会开来接走它们。
4. 槽位被占满就失败，所有车清空即过关。

## 运行

纯静态单文件，无需构建：

```bash
python -m http.server 8000
# 浏览器打开 http://localhost:8000 ，用手机模式（F12 → 设备模拟）体验最佳
```

调试：控制台输入 `mlgc.go(5)` 直接跳到第 5 关。

## v0.3.1 猫咪养成（图鉴改版）

图鉴从“收集进度条”改成“猫咪养成”：送猫咪回家 10 / 30 / 80 只升到 Lv1 / Lv2 / Lv3，每次升级奖励 30 / 60 / 100 金币。技能**只在闯关模式生效**，今日挑战保持公平。

| 猫咪 | 技能 | Lv1 / Lv2 / Lv3 | 专属皮肤 |
|---|---|---|---|
| 🟠 橘子 | 开门红：每关第一次三消额外金币 | +3 / +5 / +8 | 👑 小皇冠 |
| 🔵 蓝莓 | 后悔药：每关免费撤回（第 3 关起） | 1 / 2 / 3 次 | 🎩 绅士礼帽 |
| 🩷 桃桃 | 热闹派对：连击额外金币 | 连击数 × 1 / 2 / 3 | 🎀 蝴蝶结 |
| 🟢 抹茶 | 佛系复活：每关概率获得一次免费复活 | 30% / 60% / 100% | 🌿 抹茶叶 |
| 🟣 葡萄 | 老司机：三消中有长车时额外金币 | +4 / +7 / +10 | 🕶️ 酷墨镜 |
| 🟡 柠檬 | 危险预知：槽位快满时高亮推荐的车 | 剩 1 / 2 / 3 格时 | 🌼 小雏菊 |
| ⚪ 汤圆 | 每日礼物：每天第一局闯关送随机道具 | 1 / 2 / 3 个 | 🧣 暖围巾 |

- **皮肤**：Lv3 免费解锁，或花 300 金币提前购买；可在猫咪详情页佩戴 / 取下，佩戴后停车场和槽位里的小车都会戴上。
- **图鉴界面**：卡片换成猫脸画像，显示等级和升级进度；点卡片看详情：设定台词、三级技能表（当前等级高亮）、皮肤按钮。
- **即时反馈**：第一次送某种猫回家弹出“新猫咪入册”，升级时提示等级和奖励，技能触发时在巴士上方飘字。

## v0.3 更新内容
