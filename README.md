# 喵了个车 · H5 可玩原型

微信小游戏《喵了个车》的玩法验证原型：**挪车解谜 + 槽位三消**，题材是可爱的猫咪小车。

> 目的：在投入 Cocos Creator 正式开发前，先用最低成本验证“是否上头”。

## 怎么玩

1. 点击停车场里的小猫车，车头方向前方没有遮挡就能开出去。
2. 开出的车进入底部 7 个等候槽位，**凑齐 3 辆同色**自动坐巴士离开。
3. 槽位被占满就失败，所有车清空即过关。

## 运行

纯静态单文件，无需构建：

```bash
python -m http.server 8000
# 浏览器打开 http://localhost:8000 ，用手机模式（F12 → 设备模拟）体验最佳
```

调试：控制台输入 `mlgc.go(5)` 直接跳到第 5 关。

## 原型里已验证的设计点

| 设计点 | 实现 |
|---|---|
| 新手爽感 | 第 1 关 9 辆车、3 种颜色，10 秒可过 |
| 难度断崖 | 第 2 关约 45 辆车、9 种颜色（随机策略机器人通关率约 16%） |
| 关卡必可解 | 按“离场顺序”逆向摆车 + 颜色分块分配，保证存在 7 格内的解 |
| 差一点点 | 失败弹窗显示“只差 N 辆车 / 已完成 xx%” |
| 激励视频点位 | 撤回、移出 3 辆、洗牌、加一格、复活、过关双倍金币（均为模拟广告） |
| 插屏点位 | 第 3 关之后每 2 关一次（模拟） |
| 反馈 | 消除粒子、音效、震动、被挡时抖动 + 挡路车闪红 |

左下角显示本次会话的模拟广告观看次数，方便内测时估算人均广告次数。
